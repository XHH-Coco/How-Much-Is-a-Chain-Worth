# 链值多少？ / How Much Is a Chain Worth?

> 把一条高分子链压缩成一个重复单元之后，还有多少性质方差解释不了？这个比例会随着数据量增加十倍而缩小吗？

## 二、阶段计划

| 阶段 | 做什么 | 产出落在 | 验收标准 |
|---|---|---|---|
| **P0 环境** | 三个 conda 环境装包、锁版本 | `environment/` | 每个环境能 import 自己的核心包，版本可复现 |
| **P1 获取数据** | 下载四个基准，算摘要 | `data/raw/` + `data/manifests/` | 条数与官方发布一致，每个文件有 sha256 |
| **P2 清洗与划分** | 统一记录格式；官方划分做成只读快照 | `data/interim/` + `splits/` | 划分文件带校验，任何人不得改写 |
| **P3 配置** | 任务、实验、处理的配置文件 | `configs/` | 每个配置能被读取并校验，错配即报错 |
| **P4 代码** | 按分层实现 | `src/chainworth/` | 单元测试通过，同 seed 两次结果逐位相同 |
| **P5 运行** | 按配置跑，逐次落记录 | `results/raw_runs/` | 每个数字都能追到某一次运行 |
| **P6 图表与文档** | 出图、写方法与结论 | `results/figures/` + `docs/` | 图能由脚本一键重画 |

阶段之间不并行。上一阶段没验收，下一阶段不开工。

## 三、目录约定

| 路径 | 放什么 | 明确不放什么 |
|---|---|---|
| `configs/tasks/` | 单个任务的配置（数据集、目标性质、划分引用） | 权重、运行结果 |
| `configs/experiments/` | 一次实验要跑哪些任务、哪些模型、几个种子 | 任务本身的定义（那在 `tasks/`） |
| `data/raw/` | 原样下载的文件，只读 | 任何清洗后的数据 |
| `data/interim/` | 中间产物，可重建 | 唯一副本 |
| `data/processed/` | 喂给模型前的最终表 | 原始文件 |
| `data/manifests/` | 文件清单、条数、sha256（**要入库**） | 数据本体 |
| `splits/` | 划分索引，**只读**（要入库） | 生成脚本的临时输出 |
| `src/chainworth/` | 包代码，按职责分层 | 一次性脚本 |
| `scripts/` | 阶段入口脚本（`00`–`07` 编号） | 可复用的库代码 |
| `results/raw_runs/` | 每次运行一个记录文件（**要入库**） | 模型权重 |
| `results/aggregate/` | 汇总表（要入库） | 手改的数字 |
| `results/figures/` | 图（可由脚本重画） | 截图 |
| `tests/` | 单元测试与小型合成样例 | 真实数据副本 |
| `docs/` | 方法、决策记录、操作手册 | 与 README 重复的内容 |

## 四、三条硬规则

1. **原始数据永不入库。** 仓库里只有指针（URL、sha256、条数）。
2. **`splits/` 只读。** 划分一旦确定，任何代码不得重算；要换划分，出新版本文件。
3. **结论必须对应一条运行记录。** 没有 run 记录的数字，不写进任何文档。
