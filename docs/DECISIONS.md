> **谁改口径谁登记。** README 第九节规定：冻结物不得原地改，要改就出新版本文件，并在这里记一条（为什么改、影响哪些 run）。**没写进这里的口径变更，视为没发生过**——后人只会看到两个互相矛盾的数字，查不出是哪一个被改过。
