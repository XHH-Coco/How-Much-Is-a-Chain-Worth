## ① Λ 有多大：多数任务上链臂没有收回方差

**链臂（A3 图网络 / A4 冻结编码器）相对单元臂（A2 描述符 + 指纹 + XGBoost）的剩余方差回收率，
在 19 个「任务 × 臂」格子里有 12 个为负，中位数 −0.10。**

- 证据：图 1（`results/figures/fig1_lambda_heatmap.pdf`）+ `results/aggregate/lambda_ci.csv`。
- 区间：最稳的负值是 OpenPoly 的 **Tm，A3 的 Λ = −0.859**（75 行可算、三种子 × 5 折 × 5 档）；
  最大的正值是 `pb26_homopolymer_density` 的 A3 **+0.638**，但那一格只有 **6/15 行可算**
  （另外 9 行的 A2 已到 R² ≥ 0.95，按 D-1 不输出 Λ）。
- **反例条件**：A3 用的是官方默认超参、**一次没调**，A2 调过 30 次（预注册协议 D-51）。
  若把 A3 也做同等预算的调参，符号可能变——这是这条结论最直接的威胁，也是它必须写"对 A3 而言"的原因。

## ② 与分层的关系：H1 按预注册判据被证伪，但证伪由一个不可判点驱动

**PolyBench 6 个任务上，Λ 与三层划分的 Spearman ρ = 0.000（A3）/ +0.239（A4），均低于 0.5 门槛，
且两臂各出现 2 处跨 ≥2 层倒序 → H1 被证伪。**

- 证据：图 2 + `results/aggregate/h1_ordering.csv`（`scope=summary_all` 行）。
- 区间与代价：全部 **4 处跨层倒序的每一处都含 `pb_t3_dielectric_loss`**。去掉这一个任务，
  ρ 变成 **+0.527 / +0.949**，判定翻成 `H1_not_refuted`。那个点的区间宽 **2.19 / 1.27**
  （`undecidable`）、样本量只有 **279 行**、A3 的 R² 是 **−0.009**。
  **事后剔除它来改判据是不允许的**（D-73 同型错误），所以结论仍按预注册口径写成"被证伪"。
- 机制：**tier 与样本量完全反序**（ρ = **−0.956**；tier1 = 8,055 / 3,796 行 → tier3 = 279 / 228 行），
  tier 同时代理「需要链信息」与「数据少 30 倍」。
- **反例条件本轮已测掉一半**：把 tier1 的训练集下采样到 tier2 的实际训练行数（**497 / 723**）重训，
  Δ = Λ(tier1) − Λ(tier2) 仍是 **−0.033 [−0.042, −0.024]**（n=497）与 **−0.087 [−0.153, −0.022]**
  （n=723），两个区间都排除 0（`results/aggregate/n_matched_summary.csv`）。
  所以 **"混淆"不是 ρ ≈ 0 的原因**：t1→t2 的方向与 H1 一致且稳，折断发生在 tier3 内部
  （`pb_t3_iwlt` **+0.068** vs `pb_t3_dielectric_loss` **−1.479**）。
  没测的是 t3——它只有 228/279 行，**无法往上匹配**，这一步只能等新数据。

## ③ 数据能不能买到：H2 没有被推翻，但 κ 的负号只活在分母不稳的区间里

**交替共聚集上 κ = −0.0863 [−0.1053, −0.0672]（区间整段 < 0），但 Λ 从 +0.2946 只降到 +0.1915
（减半比 0.650，未到 0.5）→ 按提案的两个证伪条件，H2 未被推翻。**

- 证据：图 3（首页图）+ `results/aggregate/kappa.csv`。
- **四个口径一起说，不能只引一句**：
  | 口径 | κ | 减半比 | 会不会判成 H2 被推翻 |
  |:--|--:|--:|:--|
  | 预注册（全部档位、最小档为起点） | −0.086 | 0.650 | 否 |
  | 去掉最小档重拟合（`kappa_leverage.csv`） | −0.224 [−0.241, −0.205] | — | — |
  | 只用分母 ≥ 0.05 的两档（300 / 1,000） | **+0.398（正号）** | — | 否 |
  | 起点改取峰值档（事后） | −0.086 | **0.380** | **会** |
- 关键限定：40 格里 **23 格**的分母 `1 − R²_unit < 0.05`（交替集从 n = 3,000 起 A2 就到 0.951）。
  Λ 逐档是**驼峰**（+0.295 → **+0.503** → +0.192），负号来自分母最小的那三档。
- 均聚集**不报 κ**：3 档里 `1,000 → 1,440` 只隔 0.158 dex，实质是两点连线（D-74）。
- **换一把尺子（H2′，`results/aggregate/metric_sensitivity.csv`）**：同一批折、同一批档位，
  绝对口径 ΔR² 从 **+0.0395** 降到 **+0.0066**，首末比 **0.167 [0.138, 0.198]**，**减半成立**；
  而 Λ 的比值是 **0.650 [0.570, 0.739]**。两个区间**不重叠**，分歧不是边缘性的。
  机制在分母：`1−R²_unit` 从 0.135 掉到 0.034（0.25×），分子只降到 0.167×——**Λ 的驼峰是分母造的**。
  H2′ 是本轮新提的假设、没有预注册，故**不写进上面这句结论**，只并列报（D-77）。
- **反例条件**：若 A2 在大档位达不到 R² = 0.966（例如换一个更难的层划分，或换低 n 端更稳的链臂），
  分母足够大，κ 的符号可能翻。现有数据无法在"分母稳"的位置上检验 H2——这句话本身就是结论的一部分。
  注意 H2′ 已经把这条反例条件**换了个形式验过一遍**：分母不再参与时，"减半"立即成立。

## 三条结论共用的边界

1. **A5（同一架构下注入链信息）不可构造**——不是没跑：预登记的链输入（重复单元数、连接权重）
   在数据里不存在（D-47/D-48），`a5_chain` = 0 条是结果而不是欠账。**真打乱对照也未产出**，
   但有一个**逐任务**的维度地板（D-46 的 `null_calibration`，本轮扩到全部 8 个任务：
   中位 **0.0022**、最大 0.0192）。8 个任务里只有 `pb_t1_tg`（0.0004）与 `pb26_polymetrix_tg`（0.0006）
   的 A3 增益落在地板之下，其余 6 个都过得了噪声门槛。因此 H3「增益来自信息还是架构」
   **无法判定**——现有 A3、A4 都是"换架构"（图 4 的两个灰框）。
2. **只有一种 label source**（6/6 是 `experimental`），提案要求的跨来源 τ 与 leave-one-source-out
   **不可评**（`h1_heterogeneity.csv` 写 `not_evaluable_single_source`）。
3. **所有区间只含测试集抽样不确定度**（配对 bootstrap，B = 2,000）。scaling 只有 seed 0，
   GNN 的初始化方差不在区间内；折间标准误占 bootstrap 半宽的 **53%（交替）/ 60%（均聚）**，
   合进去后交替集区间变为 [−0.114, −0.059]，**仍整段 < 0**，不改变 H2 的判定。
