**改法**：把"只挡带 `n_level` 的记录"换成三条白名单，来源是 `main_table.yaml` 本体（唯一出处）：

```python

           and str(r.get("task", "")) in tasks
           and str(r.get("arm", "")) in arms]
if expected and len(unique) > expected:
    raise SystemExit(...)                        # 宁可炸，不许悄悄变长
```

**证据**：


## 5. 两条结构性问题

### S1 · 跨人交付没有接口契约 —— **已落实**

`分工_C` 母本新增 **§3.5「跨人交付接口」**：六类交付各要"三样东西"，清单必须含六个字段
（`path` / `sha256` / `size_bytes` / `committed` / `where` / `deletable_after`），
并且**期望条数必须写成断言**（96 / 32 / 192 / 922 各有一处唯一出处）。
开头就把本轮三件事（pack 对不上、45 份找不到、96→111）并成一句话：**同一个缺口**。

### S2 · 冻结表变更权集中 —— **已落实**

同节新增「冻结物的变更窗口」：每批验收结束后 **24 小时内批量收** v+1，窗口外只接受"会导致错误结论"的紧急修订。
依据是本轮两条悬空（`cell` 段、Q-10）各自拖了两轮。
