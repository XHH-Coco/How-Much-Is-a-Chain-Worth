# Λ / ΔR² 表读法（`results/aggregate/lambda_ci.csv`）

> 生成：`python scripts/06c_lambda.py`（2026-11-17，D-1/D-2 首版）。**一行一个 (task, arm, fold, seed)**，
> 不是一行一个任务——区间来自每一折每一自己那一批测试点的残差重采样，不能跨折合并。
> 逐格汇总在 `summarise_by_arm()` 的返回值里（脚本会把表打在屏幕上）。

## 1. 这张表是什么

$\Lambda = (R^2_{\text{chain}} - R^2_{\text{unit}}) / (1 - R^2_{\text{unit}})$

- `unit` 臂 = **A2 经典**（只给重复单元描述符）；
- `chain` 臂 = **A3 图网络** 或 **A4 polyBERT**；
- 两个 R² 都**从预测重算**，不读记录里的 `metrics`——实测 907 条可核记录、642 个值，
  与记录逐条差 < 1e-6（`test_recomputed_scores_match_every_run_record`）。

规模：**321 行** = OpenPoly 3 性质 × 75 + PB26 2 任务 × 5 折 × 3 种子 × 2 臂 + PolyBench 6 任务 × 3 种子 × 2 臂。
`a1_floor` 不进配对（它是地板，不是"只给重复单元"的模型）；OpenPoly 的折 5–9 是敏感性批次（D-36），不进主表。

## 2. 三条硬规矩（机器守着，不是文档提醒）

| 规矩 | 实现 | 守它的测试 |
|:--|:--|:--|
| **不 clip**：负 Λ 照原样报 | `value` 直接用算出来的数 | `test_negative_lambda_is_reported_not_clipped` |
| **分母不稳就不报**：`R²_unit ≥ 0.95` 时 `value = NaN`、`reportable = False`，只留 `ΔR²` 与 `diagnostic` | 类型上就拿不到可报值 | `test_threshold_exactly_095_is_unstable` |
| **0/0 不崩**：`R²_unit = R²_chain = 1` → NaN + warning | `lambda_from_r2` 不抛异常 | `test_zero_over_zero_returns_nan_with_a_warning` |

区间：**配对**残差 bootstrap，B = 2000、`seed = 20261117`，**同一组下标同时抽两条臂**
（各抽各的会让区间虚宽——`test_independent_resampling_would_widen_the_interval` 实测了这一点）。
同种子两次逐位相同。

**三条能说的**（每条都带区间，且都能被后面的图复核）：

1. **Λ 基本不为正。** 303 个可报值里只有 **127 个 > 0**，中位 **−0.098**，最负 **−3.32**。
   六个 PolyBench 主表任务的 Λ 都落在 −1.5 到 +0.17 之间，**没有一个是"显著大于 0"**。
2. **区间在测试点多的任务上够窄，在少的任务上不够窄。** `pb_t1_tg` 的 2,417 个测试点给出 0.15–0.21 的

3. **`pb_t3_dielectric_loss` 的 Λ = −1.48 是这批里最大的负值**，且三种子的 run 间 sd 只有 0.039：
   这不是噪声，是"链臂在这个任务上稳定地更差"。

## 4. 三条必须一起引用的限制（不写就是夸大）

1. **A2 调过 30 次超参，A3/A4 没有同等对待。** A2 走的是预注册搜索协议（30 trials × 5 折，
   `a2_best_params.csv`），A3/A4 用的是各自配置里冻结的超参。所以负 Λ 的**一部分**可能是
   "A2 被调得更好"，不是"链信息有害"。**这一条决定 H1 能不能说死**：如果 D 要写"Λ 随 tier 不动"，
   必须先说明两边的调参预算不对等。要消掉它，得给 A3/A4 同预算的搜索——那是新实验，不在 D 的权限内。
2. **Λ 是配对量，只在同一批测试点上成立。** 321 对里两条臂的测试集行集合**逐对相同**
   （`build_lambda_table()` 会检查，不同就写进 `note`；实测 0 条不同）。跨折、跨档的 Λ 不许平均后当点估计。
3. **`pb26_homopolymer_density` 的 18 行不可报，是因为 A2 已经 > 0.95**，不是链臂的问题。
   这 18 行的 ΔR² 仍可报，`lambda` 一律留空——**不许填 0**（主表缺格的同一条规矩）。

## 5. 与 H1 / H2 的关系（写清楚，别让下游误读这张表）

- **H1（分层排序）**：需要"6 个 PolyBench 任务的 Λ 与 tier 的 Spearman ρ"。现在 6 个点齐了，
  但其中 5 个 |Λ| < 0.2 且多数为负——**ρ 会算出来，但它是在一堆 ≈0 的数上排出的序**，
  按分工 D §7 的坑表，散点必须画出来，ρ 只作注释。
- **H2（数据不能补偿）**：**这张表答不了**。κ 是 Λ 对 log₁₀n 的斜率，而 `pb26_scaling_cp`
  只跑了单元臂（`arms: [a2_conventional]`），**没有链臂就没有 Λ(n)**，κ 无从拟合。
  补预算的方案另议；在补上之前，H2 只能写"未按预注册判据检验"。
